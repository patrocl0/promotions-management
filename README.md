# Promotions Management

Aplicación para administrar promociones de productos.

## Tecnologías

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod

### Backend

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose

## Funcionalidades

- Listar promociones
- Crear promociones
- Filtrar promociones
- Buscar promociones
- Cambiar estado
- Eliminar promociones
- Listar productos
- Aplicar promociones por producto o categoría

## Instalación

### Backend

```bash
cd backend-kodigo
npm install
npm run dev
```
